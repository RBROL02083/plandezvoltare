# Lucru 01A — Lectură și orientare

[Lecția detaliată de 30 de minute](../../lectii/lectia-01a.md) · [Mediul WSL](../README.md)

## Prerechizite

- VS Code conectat la Ubuntu în WSL și un browser Windows.
- Acces la [documentația publică Jenkins](https://www.jenkins.io/doc/book/pipeline/jenkinsfile/#creating-a-jenkinsfile).
- Nu ai nevoie încă de Jenkins pornit, repository de aplicație, SSH sau cont AWS.

## Instalare

**Nicio instalare.** VS Code și WSL există deja. Deschide lecția din linkul de mai sus. Nu executa exemplul de pipeline în terminal: este cod pentru Jenkins, nu Bash.

## Lucru în acest folder

Poți salva aici schița laboratorului și răspunsurile tale, fără date de serviciu. Urmează cele trei intervale din lecție: citire, desenarea fluxului și verificare.

## Verificare

- Identifici controllerul, agentul, workspace-ul, etapele și JAR-ul.
- Explici de ce un test eșuat oprește arhivarea în exemplu.
- Distingi arhivarea de publicare și deploy.

Revino apoi la [instalarea din lecția 01](../lectia-01/README.md). Aceste 30 de minute fac parte din cele 90 de minute ale ei.
